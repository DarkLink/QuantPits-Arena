# 参与者接入与共同窗口比较

中途接入的匿名参与者通过私有规范指定来源快照、状态日期、首个决策截面、执行日和观察锚点。接入在候选代次中逐动物深拷贝研究状态，延续费用、持仓、权益和历史信号队列；不产生接入交易，不重跑既有历史。经用户明确授权，可在介绍中公开匿名参与者之间的重训关系及必要时间线；真实模型身份、架构、成员、权重与私有资产详情继续隔离保存。

已有训练资产使用 `cli.py contestant-import` 审查导入，不执行模型训练。必要的推理配置和已拟合预处理按冻结约定恢复，权重仅存于忽略目录。`contestant-fork --spec <private-spec> --dry-run` 预检，`--prepare` 准备候选身份、快照与缓存；原生 `infer-update` 和 `rollforward` 通过 `--generation <id>` 使用同一候选代次。正式登记、预测、运行目录与网页由原子发布一并安装，失败恢复保留上一完整版本。

各池补齐候选预测后，使用 `infer-verify --generation <id> --universe <pool> --date <first-decision>` 单独重算首个决策截面，与完整延长窗口中的同日预测逐值核验。核验记录绑定缓存和参与者定义摘要；五池全部通过后才允许接入结算。历史上下文中的结果只在相应决策日已成熟时可用。

新参与者的独立观察 NAV 从其锚点 1.0000 开始；继承的早期经济历史只用于私有续算。观察前曲线为空值，不加入全季排名。六名完整赛季参与者的 840 项累计比较保持原定义，观察参与者暂不分配旧累计随机检验的 p 值或百分位。五池正式随机预算继续完整执行。

网页 Compare 保留原比较工作台的预设、自由选择、三槽、基准、动物切换与动物矩阵。所有已选对象（包括可选第三槽）以最晚有效观察日起算，净值在同一收盘锚点重基；用户也可选择更晚的共同窗口。差值沿用原工作台的 Slot A−Slot B，单位为百分点；A/G 预设将 G 放入 Slot A、A 放入 Slot B，表示 G−A。卡片、图表和动物表采用完全相同的窗口，缺失动物显示不可用；不补零、不回填历史，不借用全季 p 值。G 与原参与者共用详情页布局、图表和动物表，介绍明确来源及观察日期，缺少的历史指标和统计显示 N/A。

参与者身份与私有资产版本分开保存。按日期选择版本不会改变此前已冻结的信号或组合状态。后续资产激活须按用户通知明确决策日与实际执行安排；月末、行情入库或训练完成本身不授权调仓。
